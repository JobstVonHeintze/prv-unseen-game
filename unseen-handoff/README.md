`create-spec-kit`, then paste `BOOTSTRAP.md` into the first Claude Code session.

- `docs/reference/prototype-design.md` — technical design of the simulator.
- `docs/reference/story-bible.md` — the complete UNSEEN story bible, exported 2026-09-19.
